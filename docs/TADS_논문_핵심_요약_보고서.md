# TADS 논문 핵심 요약 보고서

> **논문:** _Trajectory-Anchored Dynamic Data Selection for Instruction Tuning_ (TADS)
> **목적:** 핵심 아이디어와 강점을 쉽게 전달하기 위한 요약 보고. 수식은 포함하되, 설명은 일상 비유와 예시 중심.

---

## 한눈에 보기

| 항목 | 내용 |
|------|------|
| **무엇** | Instruction tuning에서 **학습 데이터를 똑똑하게 고르는** 방법 |
| **어떻게** | 모델 자신의 내부 표현 변화 궤적을 읽어, "지금 키우는 능력에 맞는 데이터"를 매 epoch 동적으로 선택 |
| **핵심 도구** | trajectory anchor — 모델 hidden state의 변화 방향에서 뽑은 "능력 나침반" |
| **결과** | 초기 실험에서 anchor 없는 기존 방식보다 일관된 성능 향상, 추가 비용은 1% 미만 |
| **강점** | 외부 자원 불필요 · 깨끗한 ablation · 안정성 이론 보장 · 거의 공짜 |

**한 줄 요약** — TADS는 _"모델이 데이터를 읽으며 어디로 움직이는지"_ 를 관찰해, 그 방향과 잘 맞는 학습 데이터에 가산점을 주는 데이터 선택 방법이다.

---

## 1. 풀려는 문제 — 왜 데이터를 "고르는가"

**쉬운 예시.** Alpaca-GPT4 데이터셋에는 instruction–response 쌍이 **52,002개** 있다. 이걸 전부 학습시키는 대신, _가장 좋은 10%(약 5,200개)_ 만 골라 학습시킬 수 있을까? 목표는 **더 적은 연산으로 같거나 더 나은 모델**을 얻는 것이다.

수식으로는, 전체 풀 `D`에서 예산 `B`만큼의 부분집합 `S`를 고르는 문제다.

$$S \subset D, \qquad |S| = B, \qquad \rho = \frac{B}{N}$$

여기서 `ρ`는 선택 비율(예: 10%), `N`은 전체 데이터 수.

**왜 중요한가.** 연산 예산이 고정돼 있을 때는 데이터의 **질과 구성**이 **양**을 이긴다는 것이 이 분야의 경험적 합의다. 실제로 잘 고른 10%가 100% 전체 학습을 능가하기도 한다. 그래서 "무엇을 학습시킬까"가 instruction tuning의 핵심 레버다.

---

## 2. 핵심 아이디어 — 모델의 궤적에서 능력 방향을 읽다

**쉬운 예시.** 사람이 책을 한 권 읽으면 생각이 어느 방향으로든 바뀐다. 모델도 마찬가지다 — 한 샘플을 처리하는 동안 내부 표현(hidden state)이 **어느 방향으로 움직인다.** 이 움직임의 방향을 모아 보면, _그 모델이 지금 키우고 있는 능력_을 알 수 있다.

TADS는 이 "능력 방향"을 매 epoch 새로 읽어, 데이터 선택 점수에 반영한다. 최종 점수는 다음과 같다.

$$s_i^{(t)} = \underbrace{R_i^{(t)}\,a_i^{(t)}}_{\text{기존 점수 (base)}} \times \underbrace{\bigl(1 + \lambda\,\widetilde{\mathrm{align}}_i^{(t)}\bigr)}_{\text{anchor 보너스 (TADS 기여)}}$$

**쉽게 읽으면** — "원래 쓰던 점수"에 "능력 나침반과 얼마나 잘 맞는지"를 곱해 가산점을 준다.

이 곱셈 구조의 장점이 깔끔하다. `λ = 0`이면 보너스 항이 그냥 1이 되어 **기존 방식과 정확히 똑같아진다.** 즉 TADS의 효과만 깨끗하게 떼어내 측정할 수 있다(clean ablation). 또한 anchor는 정답 라벨·검증 셋·외부 평가 모델이 전혀 필요 없다 — **오직 학습 중인 모델과 데이터 풀만으로** 만들어진다.

---

## 3. 작동 원리 — 3단계로 보기

### 3-1. 재료 ① — "샘플이 모델에 한 일" 측정하기

**쉬운 예시.** 책을 다 읽고 났을 때 "처음 생각"과 "마지막 생각"의 차이가 그 책이 나에게 준 영향이다. 모델도 똑같다 — 한 샘플의 **첫 토큰**(내용 처리 전)과 **마지막 토큰**(전체 문맥 흡수 후)의 hidden state 차이를 본다.

$$\Delta h_l(x) = h_l^{\mathrm{last}} - h_l^{\mathrm{first}}$$

이 값 `Δh`(contextualisation delta)가 "이 샘플이 layer `l`에서 모델에 한 일"이다.

### 3-2. 재료 ② — 변화들의 "주축" 뽑기 = trajectory anchor

**쉬운 예시.** 무작위로 뽑은 1,024개 샘플의 `Δh`를 모으면, 표현 공간에 **길쭉한 구름**이 생긴다. 그 구름이 가장 길게 늘어난 **축**이 바로 anchor — 변화들의 "평균적인 큰 흐름", 일종의 **능력 나침반**이다.

수학적으로는 `Δh`들의 공분산 행렬에서 가장 큰 분산 방향(top eigenvector)을 고른다.

$$v_l^{(t)} = \arg\max_{\|v\|=1} v^\top \Sigma_l^{(t)} v$$

layer마다 나침반이 하나씩 만들어지고, 매 epoch 새로 갱신된다.

### 3-3. 채점 — 후보가 나침반 방향과 얼마나 맞는가

**쉬운 예시.** 새 데이터 후보를 들고 "이 샘플이 가리키는 방향이 나침반과 같은 쪽인가?"를 묻는다. 같은 쪽을 가리킬수록 — 모델이 지금 키우는 능력에 더 잘 맞는 샘플이다.

후보의 평균 표현을 나침반 방향에 **사영(projection)** 한 뒤 0~1로 정규화한다.

$$\widetilde{\mathrm{align}}_i^{(t)} \in [0, 1]$$

이 정렬도가 높을수록 2장의 점수식에서 더 큰 보너스 `1 + λ·align`을 받는다. 보너스 범위는 `[1, 1+λ]` — 즉 잘 맞는 샘플은 가산점을 받고, 안 맞아도 감점은 없다(안전한 설계).

---

## 4. 이론적 보장 — 나침반은 흔들리지 않는다

**쉬운 예시.** "anchor를 매번 무작위 샘플로 새로 뽑는다면, 그냥 매번 다른 노이즈 아닌가?"라는 의문이 들 수 있다. **Theorem 1**은 아니라고 답한다 — anchor는 epoch 사이에 **아주 조금씩만** 움직인다.

$$\bigl\|v_l^{(t+1)} - v_l^{(t)}\bigr\| \le \frac{2 C_\Sigma}{\gamma_{\min}}\,\eta_t$$

**쉽게 읽으면** — anchor의 움직임 크기가 **학습률(`η_t`) 수준으로 묶여 있다.** 학습률은 보통 아주 작으므로(예: 0.0002), anchor도 조금씩만 변한다. 고전적인 Davis–Kahan 정리로 증명된다.

**의미.** 매 epoch 다시 뽑아도 anchor는 _재현 가능한 구조적 객체_다. 일시적 노이즈가 아니라 모델의 일관된 능력 방향을 가리킨다는 뜻이다.

---

## 5. 초기 결과 — 유망한 신호

**쉬운 예시.** Qwen2.5-0.5B 모델로 보너스 강도 `λ`를 조절해 보면, 작은 `λ`(0.1)가 anchor 없는 기존 방식(`λ=0`)을 일관되게 앞섰다.

| λ (보너스 강도) | 4-task 평균 정확도 |
|---|---|
| 0 (anchor 없음) | 37.18 |
| **0.1** | **38.56** ← 최고 |
| 1.0 | 37.99 |
| 5.0 | 38.17 |
| 10.0 | 37.81 |

anchor를 켜기만 해도(λ>0) 모든 설정에서 기존 방식보다 좋았다. 추가 연산 비용은 **1% 미만** — PCA와 내적 몇 번이 전부이기 때문이다.

> 더 큰 모델(7B~14B)과 여러 데이터셋에 걸친 전면 검증은 현재 진행 중이며, 위 0.5B 결과는 그 방향성을 뒷받침하는 초기 신호다.

## 부록 — 핵심 수식 한눈에

| 수식 | 뜻 |
|---|---|
| $s_i^{(t)} = R_i^{(t)}\,a_i^{(t)}\,(1 + \lambda\,\widetilde{\mathrm{align}}_i^{(t)})$ | 최종 선택 점수 = 기존 점수 × anchor 보너스 |
| $\Delta h_l(x) = h_l^{\mathrm{last}} - h_l^{\mathrm{first}}$ | contextualisation delta — 샘플이 모델에 한 일 |
| $v_l^{(t)} = \arg\max_{\|v\|=1} v^\top \Sigma_l^{(t)} v$ | trajectory anchor — 변화 구름의 주축 (능력 나침반) |
| $\widetilde{\mathrm{align}}_i^{(t)} \in [0,1]$ | 후보가 anchor 방향과 정렬된 정도 |
| $\|v_l^{(t+1)} - v_l^{(t)}\| \le \tfrac{2C_\Sigma}{\gamma_{\min}}\eta_t$ | Theorem 1 — anchor는 학습률 수준으로만 움직인다 |

**기호:** `D` 데이터 풀 · `B` 선택 예산 · `ρ` 선택 비율 · `λ` 보너스 강도 · `R` 기존 reward · `a` 보조 가중치 · `Σ` 변화량 공분산 · `η_t` 학습률 · `C_Σ`·`γ_min` 안정성 상수.
